In the file server/topic-deduplication-service.ts, find the processTopics function. It accepts a similarityThreshold parameter that determines how aggressively topics are collapsed into each other. The current threshold being passed when this function is called from routes.ts is 0.5 — meaning any two topics that are 50% similar get merged into one.

This is too aggressive. Legitimate topics like "How to improve ChatGPT visibility" and "How to improve Perplexity citations" share enough words to exceed 50% similarity and get collapsed, silently reducing the topic count the user sees with no indication this happened.

Find where the merge/deduplication decision is made and add this check:

// Never merge topics that target different AI platforms

  topicA.targetPlatform &&
  topicB.targetPlatform &&
  topicA.targetPlatform !== topicB.targetPlatform;
if (differentPlatforms) {
  continue; // skip merge even if similarity score exceeds threshold
}
