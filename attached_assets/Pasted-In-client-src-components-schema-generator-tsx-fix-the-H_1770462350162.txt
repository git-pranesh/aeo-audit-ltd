Then modify the HowTo generation block (lines 142-172).
Replace the hardcoded steps with:

  const industryKey = getIndustryKey(industry);
  const howToData = INDUSTRY_HOWTO_MAP[industryKey]
    || INDUSTRY_HOWTO_MAP.default;

  const howToSchema = {
    '@context': 'https://schema.org',
    '@type': 'HowTo',
    'name': howToData.title
      .replace('{company}', companyName),
    'description': howToData.description
      .replace('{company}', companyName),
    'totalTime': 'PT15M',
    'step': howToData.steps.map((s, i) => ({
      '@type': 'HowToStep',
      'position': i + 1,
      'name': s.name,
      'text': s.text
        .replace('{company}', companyName)
        .replace('{url}', websiteUrl),
    })),
  };

The existing getIndustryKey() function on line 86 already
maps industry strings to keys — reuse it for the HowTo map.

Do NOT change the FAQ schema generation (it's already good),
the Article schema, the LocalBusiness schema, the Copy Code
