Create a new frontend component to display the citation snapshot results.

Create file: `client/src/components/citation-snapshot.tsx`

This component should:

1. Accept props: `citationSnapshot` (the CitationSnapshotResult data from the audit response, can be null)

2. If `citationSnapshot` is null, show a muted card that says "Citation snapshot unavailable for this audit"

3. If data exists, display:

   **Header section:**
   - Large number showing mention rate: e.g., "2 out of 12 prompts" with a percentage
   - A visual indicator (red if 0%, yellow if 1-25%, green if 25%+)
   - Text: "We asked AI platforms real questions about your industry. Here's whether they mentioned you."

   **Prompt Results section (expandable/collapsible):**
   - For each prompt result, show:
     * The prompt text (e.g., "What are the best marketing agencies?")
     * ✅ or ❌ icon showing if they were mentioned
     * If mentioned: show the context sentence highlighted
     * If not mentioned: show "Competitors mentioned instead:" with the list
     * Expandable area showing the full AI response text

   **Top Competitors section:**
   - Show a ranked list of competitors that AI mentioned most often across all prompts
   - Show count next to each (e.g., "HubSpot — mentioned in 8/12 prompts")
   - Style as a simple table or ranked list

   **Action callout:**
   - If mention rate is 0%: "AI platforms don't know about you yet. Your AI Readiness playbook below shows exactly what to fix."
   - If mention rate is 1-25%: "You're starting to appear, but competitors are dominating. Follow the playbook to close the gap."
   - If mention rate is 25%+: "You're being mentioned! Focus on the playbook to increase your frequency and ranking."

4. Use existing shadcn/ui components from your `client/src/components/ui/` folder:
   - Card, CardHeader, CardContent from card.tsx
   - Collapsible from collapsible.tsx
   - Badge from badge.tsx
   - Accordion from accordion.tsx
   - Use Tailwind for all styling
   - Use lucide-react icons (Search, CheckCircle, XCircle, ChevronDown, Trophy)

5. Make it responsive — works on mobile and desktop.

6. Then integrate this component into `client/src/components/audit-results.tsx`:
   - Import the CitationSnapshot component
   - Add it AFTER the platform scores section but BEFORE the topics section
   - Pass `auditData.citationSnapshot` as the prop
   - Only render it if the data exists (optional chaining)
