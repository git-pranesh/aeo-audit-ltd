Create a new service that generates actionable "fix-it playbooks" with real code snippets and templates based on content signal gaps.

Create file: `server/playbook-generator-service.ts`

This service should:

1. Export a function `generatePlaybook` that takes:
   - `contentSignals` (from content-signal-service.ts ContentSignals type)
   - `scoringResult` (the platform scores)
   - `companyIntelligence` (industry, business type, etc.)
   - `companyName` (string)

2. Return a `PlaybookResult` object:
```typescript
   interface PlaybookAction {
     id: string;
     priority: 'critical' | 'high' | 'medium' | 'low';
     title: string;                    // e.g., "Add FAQ Schema to Your Top 5 Pages"
     targetPlatform: string;           // e.g., "chatgpt", "gemini", "all"
     estimatedImpact: string;          // e.g., "Could improve ChatGPT score by 15-20 points"
     timeToImplement: string;          // e.g., "30 minutes"
     difficulty: 'easy' | 'medium' | 'hard';
     currentState: string;             // e.g., "0 FAQ schemas detected"
     targetState: string;              // e.g., "5+ FAQ schemas across key pages"
     stepByStep: string[];             // Array of specific steps
     codeSnippet?: {
       language: string;               // "json", "html", "javascript"
       code: string;                   // The actual code to copy-paste
       description: string;            // What this code does
     };
     contentTemplate?: {
       title: string;                  // Template title
       outline: string[];              // Section headings
       tips: string[];                 // Writing tips
     };
   }

   interface PlaybookResult {
     actions: PlaybookAction[];
     quickWins: PlaybookAction[];      // Filtered: easy + high impact
     estimatedScoreImprovement: {
       chatgpt: number;
       perplexity: number;
       gemini: number;
       claude: number;
       overall: number;
     };
   }
```

3. Generate actions based on ACTUAL signal gaps. Here are the rules:

   **If `tutorialCount < 5`:**
   - Generate action: "Create Step-by-Step Tutorial Content"
   - Include a `contentTemplate` with a tutorial outline customized to their industry
   - Target platform: chatgpt

   **If `faqSectionCount < 3`:**
   - Generate action: "Add FAQ Schema Markup"
   - Include a `codeSnippet` with FAQ JSON-LD schema pre-filled with placeholder questions for their industry:
```json
     {
       "@context": "https://schema.org",
       "@type": "FAQPage",
       "mainEntity": [
         {
           "@type": "Question",
           "name": "What is [INDUSTRY-SPECIFIC QUESTION]?",
           "acceptedAnswer": {
             "@type": "Answer",
             "text": "[YOUR ANSWER HERE - aim for 2-3 sentences]"
           }
         }
       ]
     }
```
   - Target platform: gemini, chatgpt

   **If `schemaTypeCount < 3`:**
   - Generate action: "Implement Article & HowTo Schema"
   - Include both Article and HowTo schema code snippets
   - Target platform: gemini

   **If `caseStudyCount < 3`:**
   - Generate action: "Publish Customer Case Studies"
   - Include a `contentTemplate` with a case study template:
     * Title: "[Customer Name]: How They [Achieved Result] Using [Your Product/Service]"
     * Sections: Challenge, Solution, Implementation, Results, Key Metrics, Customer Quote
   - Target platform: claude

   **If `dataPointCount < 15`:**
   - Generate action: "Add Statistics and Data to Existing Content"
   - Step by step: identify top 5 pages, research 3 relevant statistics per page, add them with proper citations
   - Target platform: perplexity

   **If `frameworkMentionCount < 3`:**
   - Generate action: "Create a Proprietary Framework Article"
   - Include template with: Framework name, Problem it solves, Steps/Phases, When to use it, Real examples
   - Target platform: claude

   **If `externalLinkCount < 10`:**
   - Generate action: "Add Research Citations to Key Pages"
   - Steps: identify authoritative sources, add 2-3 citations per major page
   - Target platform: perplexity

4. Sort actions by priority (critical first), then by estimated impact.

5. Filter "quickWins" as actions where difficulty is "easy" AND priority is "critical" or "high".

6. Calculate `estimatedScoreImprovement` based on what implementing all actions would add to each platform score. Use the weights from `server/scoring-service.ts` to estimate this roughly.

7. Customize all templates and examples to the user's ACTUAL industry (use companyIntelligence.industry and companyIntelligence.businessType to generate relevant examples, not generic ones).

8. Do NOT use any AI API calls in this service. Everything should be deterministic based on the signal data. This keeps it fast and free.
